# v0.5.6

- 自动追剧的默认上传可见性改为「私人」。正片和首集 Shorts 均遵循保存的可见性设置，AI 封面成功后也不会自动公开；已有明确选择继续保留。
- 视频管理增加「AI 一键优化」，支持单个或选中的多个视频。复用自动追剧保存的服务、模型、密钥和提示词，生成标题、说明与封面预览，可编辑文案后同步到 YouTube。
- AI 同步保留视频原有可见性，检查视频资料版本；部分失败时保留已生成、已同步的进度，重试只处理未完成部分。频道切换或停止后续操作后，不再提交剩余项目。
- 视频管理增加单个和批量「更改视频状态」，支持私人、不公开、公开，并包含 Shorts。后台只修改可见性相关状态，保留标题、说明及其他元数据；设为私人时取消定时发布。
- 增加桌面环境启动检查，避免浏览器页面调用不存在的 `invoke` 后将所有剧源误报为不可用。桌面接口延迟初始化时自动检测并恢复；浏览器提供明确标注的界面演示入口，刷新、分类和榜单均使用演示数据。
- 修复下载连接池繁忙时的 `PoolTimeout`：等待连接期间不触发备用 CDN，连接池忙时有界重试，取消下载及时释放占用。

## 验证范围

- 源码回归覆盖默认可见性、AI 生成与同步、资料版本冲突、部分失败重试、批量状态修改、桌面启动检查，以及下载连接池排队与取消。
- 浏览器演示检查了启动提示、AI 生成预览和模拟同步。
- 真实 AI 服务调用及 YouTube 修改留待用户安装新版后实测。自动化测试和演示结果不替代真实服务调用结果。
- 安装包、发布提交、CI 和下载附件的验证结果以 GitHub Release 说明为准。
