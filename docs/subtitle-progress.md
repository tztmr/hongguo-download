# v0.3.1 字幕识别进度

旧运行环境在识别开始时发送 10%，直到整段音频转写结束后才发送 85%，桌面程序因此长时间显示同一个数值。任务通常仍在处理，并非停住。

新版 AI 运行环境通过 Whisper 的已解码音频帧游标发送 JSON 进度，保留完整音频转写上下文。加载模型、准备音频、识别和保存字幕使用不同阶段。识别阶段显示已处理时长和总时长，占任务进度的 10%–85%；保存字幕后才完成。模型计算尚未完成一个音频窗口时，百分比会保持不变，不按等待时间虚增。

macOS v0.3.1 使用 AI 运行环境 v4。在设置的“媒体处理模型”中更新 AI 运行环境；已安装的 Whisper 和 Demucs 模型无需重复下载。更新不会热替换已运行的识别进程，应在当前任务结束后使用新版本开始任务。Windows 的 CPU、旧显卡和现代显卡运行环境也由 Windows CI 重新构建为 v4，更新时使用对应平台清单中的校验值。不能仅更新桌面安装程序而继续使用旧 AI 运行环境。

验证：冻结后的 macOS ARM64 工作程序、已有 small 模型和 65 秒中文音频，实时输出 0%、2%、5%、10%、44%、77%、85%、90%、100%，生成 31 条中文字幕。该测试使用 CPU，不代表 GPU 性能验证。可重现命令：

```sh
python3 scripts/verify-subtitle-progress.py --worker /path/to/hongguo-ai-worker --audio /path/to/dialogue.wav --model-root /path/to/whisper-small
```

输入应是超过 30 秒且包含对白的 WAV；脚本使用临时输出目录并限制测试 CPU 线程，不改写原始音频或模型。
