# v0.3.7 自动追剧验证

2026-09-13，macOS arm64。本次把原设置预览接成 Tauri 后台任务；浏览器预览仍不可执行。

## 使用

在 macOS 软件的「自动追剧」填写 1–5 步，文字和封面分别输入自己的 Key，点击「保存设置」，再点击「启动 24 小时自动任务」，核对频道和可见性后确认。Key 只从输入保存到系统凭据库，不来自聊天或内置默认值。删除按钮随下一次保存删除对应 Key；不回传已有 Key 到页面。无 Key、失效、模型或网络错误均按服务独立回退。

切换页面不影响后台；应用须保持运行。暂停/停止保留进度，已发起的不可中断请求收尾后停下。退出后不再监控，重开按恢复设置续接。每部剧保留原始剧名、源 ID、季数与任务记录。

源站没有明确完结标记时继续观察，可关闭「仅处理已完结」。不同季数和正片/Shorts 分别查重；疑似项显示待核对。只有正片及启用的首集 Shorts 均完成，且已有上传的附件与远端处理成功，才按设置清理本任务登记的文件。文件被修改、移位或替换时保留现场。
