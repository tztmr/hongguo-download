# macOS 安装与首次打开

当前 DMG 适用于 Apple Silicon（M 系列芯片）。将“红果下载.app”拖入“应用程序”后再打开。

本项目当前使用本地临时签名（ad-hoc），尚未使用 Developer ID 签名和 Apple 公证。浏览器下载会附加隔离标记，macOS 可能提示无法验证开发者、无法打开或“已损坏”。重新下载相同版本通常不会改变这项检查结果。

## 首次打开

1. 从本项目 GitHub Release 下载 DMG，并将它的 SHA-256 与同页提供的校验文件核对。
2. 拖入“应用程序”，尝试打开一次。
3. 在“系统设置 → 隐私与安全性”中找到红果下载，点击“仍要打开”，按系统提示完成确认。

如果提示“已损坏”且系统未提供“仍要打开”，在确认来源和下载校验值后，可在终端对已安装的这一个应用执行以下命令。只有签名完整性检查通过才会清除其下载隔离标记；不会关闭系统的全局安全检查。

```sh
/usr/bin/codesign --verify --deep --strict "/Applications/红果下载.app" && /usr/bin/xattr -dr com.apple.quarantine "/Applications/红果下载.app"
```

随后从“应用程序”打开红果下载。如果签名检查失败，请重新下载，勿继续清除隔离标记。如果打开后仍闪退，请提供 macOS 版本、应用版本和完整报错。

升级只需替换“应用程序”中的应用。保留用户数据目录，不需要删除配置、下载记录或重新安装 AI 组件。

Apple 官方说明：https://support.apple.com/zh-cn/102445
