# v0.3.11 新剧范围、后台任务和目录清理

新剧监听页右上角提供设置弹窗，支持最近 1–30 天，快捷选择今天、3、7、15、30 天。按北京时间自然日包含今天；范围设置持久化，保存后重新扫描，缓存、游标和通知基线按范围隔离。未知上线日期不进入限定范围。未设置时沿用真人剧当天、漫剧及 AI 剧最新榜单的原有方式。

真人剧按选定范围逐天拉取订阅日历并完整处理当天分页；漫剧和 AI 剧按实际上线日期过滤榜单可提供的历史数据。该设置仅作用于新剧监听页面，不改变自动追剧已保存的下载范围。

后台任务默认展示未完成任务，运行中的任务优先。新增未完成、需关注、已结束、全部数量筛选，以及剧名/ID 搜索和每页 20 项分页。卡片宽窗口双列、窄窗口单列；阶段进度与下载集数分开，完成任务不显示进度条，详情可展开，静态流水线默认折叠。

上传及全部启用的后续上传均成功后，按配置清理媒体。同时启用删除单集、删除成片时，确认本任务标记和专用目录后清理下载凭据、文案缓存、下载附带简介/封面、匹配任务的 AI 结果凭据，并从内向外删除空目录。保留字幕开启时，字幕原样留存在 `自动追剧/字幕留存/<任务目录名>/<原相对路径>`，原子写入并核对哈希后才删除源字幕。未知文件、被修改的媒体、冲突的留存字幕和链接不会被静默覆盖或递归删除。

任务目录删除后，应用中央状态继续保留剧名、源 ID、季数、频道和上传记录。升级时对旧的已完成且开启完整清理的任务补做清理，不重复下载或上传。清理在阻塞工作线程执行，任务结果明确显示目录删除、字幕留存位置或保留原因；清理版本随完成状态保存，正常完成的任务不反复重排。

验证：前端 365 项；Windows Rust 253 项，3 项忽略；Python 118 项通过、2 项跳过。浏览器使用现有 Playwright 和隔离的 UI 样本验证弹窗保存、即时范围过滤、Escape/焦点恢复、后台任务筛选/搜索，以及 1440 和 900 像素布局，无页面错误。实际用户任务只做只读排查，未启动上传或执行现场删除。
