## 已修复的问题

### 1. 导航与小窗口布局

- 九个入口分为“找剧”“自动处理”“任务与发布”，设置固定在底部。
- 滚动只作用于导航内容，避免侧栏横向溢出；当前页标记不会被边缘裁掉。
- 在应用最小窗口 `1180×760` 下，九个入口全部可见。
- 详情栏在矮窗口采用紧凑封面与指标间距。实测首页剧集网格高度为 `110px`，可看到两排完整集数，下载按钮仍在可视区内；内容过高时详情栏可滚动。

### 2. 切页与异步结果

- 首页进入空榜单或失败榜单时，旧剧目及下载选择立即清空，避免误下载上一页内容。
- 切页同时使旧列表、目录和指标请求失效；旧分页请求的结束回调不能改变新请求的忙碌状态。
- 自动追剧和设置按首次访问挂载、切页隐藏，保留输入和滚动位置。自动追剧隐藏时暂停两秒一次的前端快照轮询，返回后刷新状态但不覆盖未保存草稿。
- 浏览器复现：最多集数从 `300` 改为 `123`，转到设置再返回，仍为 `123`；同时只有当前页面可见。

### 3. 设置保存与错误反馈

- 设置保存以最后成功持久化的值为基准，叠加尚未完成的修改。两个连续保存均失败时，不再恢复到第一个失败值；前一个保存成功时，也不会暂时覆盖后一个未完成修改。
- 目录选择进入同一保存队列，并阻止重复打开选择器。
- 设备池或媒体组件读取慢，不再阻塞下载设置显示。设置读取失败显示错误及“重新读取设置”，组件与设置错误分别保留。
- 下载设置尚未读取成功时，不使用演示目录创建实际下载任务。
- 下载管理页的目录打开／定位失败与设置保存失败能在当前页面看到，并可进入设置处理。
- 通知权限指引使用通用系统文案，适用于 Windows 与 macOS。

### 4. 任务进度与删除

- 媒体与 YouTube 先订阅事件，再读取初始快照；等待快照时收到的新进度、新任务不会被旧快照覆盖。
- 媒体暂停、恢复、重试、新建，以及 YouTube 任务操作的迟到回执不能覆盖之后收到的状态。
- 已成功删除的任务不会因迟到事件、旧快照或操作回执重新出现在列表中；删除失败保留原任务。
- YouTube 切换频道、撤销授权和移除凭证返回的完整快照，合并期间产生的新任务状态。
- 多个 YouTube 操作并行时，全部结束才解除忙碌状态，避免提前开放账号操作按钮。

### 5. 分页与服务状态

- AI 推荐按 `bookId` 去重，并记录已请求的游标；重复游标、循环游标或缺失游标停止翻页。
- 加载更多失败保留已加载列表，显示结构化错误并重试同一页。
- 侧栏服务状态由实际健康检查维护，每 30 秒刷新；某个上游推荐或榜单接口报错不会被当成本地服务停止。
