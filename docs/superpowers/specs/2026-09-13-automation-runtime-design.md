# 自动追剧后台执行

用户已确认把现有 1–5 步接成真实运行，新增启动、暂停、停止、日志与重启恢复。复用 Tauri 下载、媒体队列、YouTube 队列与 AI sidecar，不建立浏览器定时任务。应用需要保持运行；退出后不声称仍在监控，重开按恢复设置续接。

配置保存与启动分离；保存已有草稿迁移到后台持久化配置，运行期间只影响下一次启动。每项任务保存当时配置、源身份、季数、频道、目录、每集路径、媒体任务 ID、上传 ID、失败次数及下一次重试时间。确定性上传 ID 和媒体请求恢复防止崩溃重发。暂停/停止停止扫描和新阶段，当前不可中断请求收尾后停下，媒体与上传任务暂停。继续时复用进度。

扫描沿用新剧及新剧榜分页，all 不限定上线日期，today 按北京时间，new 使用新剧榜。关键词、类型、方向、完结条件逐项执行；不把无完结状态当完结。没有完结证明的项目观察并定期复查。第一集实际画幅检查后再下载剩余剧集。总目录不完整不合并。

查重使用 v0.3.6 季数和视频类型逻辑；下载前查重、上传前再核对。仅可能重复时转待核对，可用户确认继续或跳过。正片和首集 Shorts 分别保留状态；首集仅在尺寸/时长合格时上传，不裁剪、不截断。Shorts 不支持 API 自动绑定相关视频，只显示需在 Studio 关联的结果，不编造已关联。

使用固定文本和图片提示词。两个 Key 独立保存在系统凭据库，草稿与日志不含 Key，不回传 Key。缺失/失效回退源信息；其余 AI 网络/模型错误记录并回退源信息，避免自动重复扣费。成功结果落盘再继续；崩溃时结果不明的生成不自动重发。原始海报用于参考图模式；未提供参考图不得假称参考。

清理延后到正片和启用的 Shorts 完成处理、封面/字幕成功后，仅清理此任务确切生成、路径仍在专用目录且内容身份未变化的媒体文件。保留源 ID/季数/上传记录与日志。失败保留文件。任务目录保留剧名、源 ID 与季数，每频道独立，避免清理另一频道任务。

真实实现显示后台快照和进度，不再显示预览启用按钮。浏览器演示保持明确不可真实执行；真实运行验证可用显式私享单剧测试，不自动启动用户的不限范围批量发布。
